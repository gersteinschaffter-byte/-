# Changelog v0.0.105

## 🎬 AI 导演增强（稳定性 + 可玩性）

- 新增导演词条类型：`enemy_spd_mult` / `ally_spd_mult`，可影响战斗节奏。
- 新增本地模板“风暴协奏”，提供速度博弈型词条。
- `formatMods` 改为中文可读标签展示，避免内部字段名直接暴露。
- DeepSeek 返回解析增强：支持纯 JSON、代码块 JSON、文本中嵌入 JSON 三种格式。
- 新增词条强度估算与风险归一化，自动矫正 `risk`，降低模型输出与实际难度不一致问题。

## ⚔️ 战斗联动

- BattleScene 现在会把导演速度词条作用到双方 `spd`，让“速度导演词条”真正影响先后手与战斗节奏。

## 📦 版本

- 版本号升级到 `0.0.105`。
