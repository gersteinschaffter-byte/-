# Changelog v0.0.103

## D2 · GameState 工程化（二期）

### ✅ 战斗奖励：原子化（batch）
- 胜利结算的【金币/钻石/碎片/宝箱/关卡推进】改为一次 `state.withBatch()` 提交。
- 避免中间态导致 UI/存档不一致；减少多次刷新/日志刷屏。

### ✅ 宝箱开启：原子化（batch）
- 先校验宝箱类型与数量，再在 `state.withBatch()` 内一次性完成【扣宝箱 + 发放钻石/金币/碎片】。
- 避免异常情况下“宝箱被扣了但奖励没发”的风险。

### ✅ 英雄升星：统一入口
- 新增 `GameState.tryStarUpHero()`：原子化完成【扣万能碎片 + 升星】。
- 英雄详情页【升星】按钮已改用该接口。

### ♻️ 英雄升级：更规整
- `tryLevelUpHero()` 改为单次 batch 提交（扣金币 + 等级+1），减少多次事件触发。
