# CHANGELOG v0.0.85 — Bugfix: 主城按钮不显示 + 滚动卡顿

## 🐛 Bug 修复

### 主城按钮不显示（严重）
**根因**: `playEnterAnimation()` 在 `onEnter()` 中执行，此时元素位置全是 (0,0)。
`slideIn` 捕获了 `finalX=0` 作为动画目标，然后 `onResize()` 设置了正确位置，
但 Tween 的 `from` 在首次 update 时捕获到正确位置，结果动画从正确位置→0，
将按钮移出可视区域。同时 alpha 动画与位置动画时序冲突导致元素不可见。

**修复**: 
- `onEnter()` 不再直接播放动画，只设置 `needsEnterAnim = true` 标记
- `onResize()` 执行完位置布局后，检测标记，此时播放动画（位置已确定）
- `onExit()` 恢复所有元素 alpha=1，防止残留状态

### 滚动坐标系不匹配（体验）
**根因**: `e.global.y` 返回屏幕像素，但 `scroll.y` 在虚拟坐标系中。
当 `world.scale < 1`（手机竖屏缩放后），拖动 100 屏幕像素只产生 100 虚拟像素偏移，
但实际应该产生 `100/scale` 虚拟像素。导致手指拖动和画面滚动比例不匹配，感觉有阻力。

**修复**: `dy` 和 `stepV` 除以 `world.scale.x` 转换到虚拟坐标

## ⚡ 性能优化

| 优化项 | 修改前 | 修改后 | 效果 |
|--------|--------|--------|------|
| 星点数量 | 160颗 | 50颗 | 减少 69% draw 调用 |
| 星点重绘频率 | 每帧 | 每4帧 | 减少 75% 重绘 |
| 星点光晕 | 亮星额外画光晕圈 | 取消光晕 | draw 减半 |
| 粒子池 | 60个 | 30个 | 内存减半 |
| 粒子发射率 | 0.4/帧 | 0.15/帧 | 减少 62% |
| 粒子光晕 | drawGlow: true | false | draw 减半 |
| 粒子重绘 | 每帧 | 每2帧 | 减少 50% 重绘 |
| 滚动摩擦力 | 0.88 | 0.93 | 更顺滑惯性 |

**综合效果**: 每帧 Graphics 操作从 ~400次 降至 ~50次，移动端帧率预计提升 30-50%
