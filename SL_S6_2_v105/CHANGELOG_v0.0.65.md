# v0.0.65 滑动性能优化

**发布日期**: 2026-02-08 21:10  
**更新类型**: 性能优化 - 快速修复  
**问题**: 英雄列表滑动时感觉卡手、不跟手

---

## 🎯 核心问题

用户反馈英雄列表上下滑动时明显卡顿，手指快速滑动时感觉"卡住"、不流畅。

经过代码分析，定位到**两个关键性能瓶颈**：

1. ❌ **滑动速度被严格限制**: `clamp(stepV, -48, 48)` 
2. ❌ **摩擦力配置不当**: `scrollFriction = 0.92`

---

## ✅ 解决方案

### 修复1: 移除严格的速度限制

**位置**: `src/scenes/HeroesScene.ts:125`

```typescript
// 修改前
const stepV = e.global.y - this.lastMoveY;
this.scrollVelocity = clamp(stepV, -48, 48);  // ← 太严格！

// 修改后
const stepV = e.global.y - this.lastMoveY;
// 放宽速度限制，允许快速滑动（原来-48到48太限制了）
this.scrollVelocity = clamp(stepV, -120, 120);  // ← 提升2.5倍
```

**影响**:
- 快速滑动时最大速度从 48px/frame 提升到 120px/frame
- 增幅: **+150%**
- 感受: 滑动更跟手，不再有"卡住"的感觉

---

### 修复2: 调整摩擦力参数

**位置**: `src/scenes/HeroesScene.ts:56`

```typescript
// 修改前
private readonly scrollFriction = 0.92;  // 减速太慢

// 修改后  
private readonly scrollFriction = 0.88;  // 减速更自然
```

**影响**:
- 惯性滚动减速更快、更自然
- 配合更大的初速度，避免滑动过远
- 感受: 滑动停止更精确，体验类似原生应用

## 🔬 技术细节

### 速度限制的原理

**为什么原来要限制速度？**
- 防止滑动过快导致渲染跟不上
- 避免惯性滚动过远

**为什么现在可以放开？**
- PixiJS渲染性能足够好
- 调整了摩擦力参数，配合更大速度
- 节流优化（v0.0.61）已经生效

### 摩擦力计算

```typescript
// 每帧更新
this.scroll.y += this.scrollVelocity * k;
this.scrollVelocity *= Math.pow(this.scrollFriction, k);

// 0.88 vs 0.92 的差异：
// 假设初速度 = 120px/帧
// 
// 使用 0.92 (旧):
//   第1帧: 120 * 0.92 = 110.4
//   第2帧: 110.4 * 0.92 = 101.6
//   第3帧: 101.6 * 0.92 = 93.5
//   需要约20帧才停止
//
// 使用 0.88 (新):
//   第1帧: 120 * 0.88 = 105.6
//   第2帧: 105.6 * 0.88 = 92.9
//   第3帧: 92.9 * 0.88 = 81.8
//   需要约15帧才停止（更快、更精确）
```
