# v0.0.101

## 工程化：调试面板（C）

### 新增
- 顶部⚙按钮改为打开【调试面板】（用于测试/排错）。
- 调试面板支持：
  - 查看关键状态：版本、关卡、队伍人数、英雄数、核心资源、日志行数。
  - 一键操作：+1000钻石、+10普通召唤券、过关+1、设置关卡、重置存档。
  - 复制日志：一键复制（或弹出手动复制）用于反馈问题。
  - 清空日志。

### 日志
- 新增 DebugLogger（内存日志，最多500行），并在关键事件自动记录：
  - 资源/背包/关卡/队伍/英雄 变更
  - 抽卡消耗与结果
  - 战斗奖励

### 兼容
- 不影响正常玩法；调试面板仅为测试辅助。
